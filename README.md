# Whisper

### OpenAI's open-source speech recognition model

Whisper is OpenAI's powerful general-purpose speech recognition model trained on 680,000 hours of multilingual audio. Freely available as open-source, it delivers near-human accuracy across languages, accents, and domains.

<br>

---

## Features

| | |
|:---|:---|
| **680K Hours of Training** | Trained on the largest and most diverse speech dataset ever assembled |
| **99 Languages** | Robust multilingual recognition across languages, dialects, and accents |
| **Open Source** | MIT licensed — run anywhere, modify freely, use in any application |
| **Multiple Sizes** | Tiny to Large models for different speed vs accuracy tradeoffs |
